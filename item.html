Why this object matters

Significance before specifications.

A production object page should begin with the reason a collector should care, then show the evidence supporting that narrative.

This prototype deliberately does not invent a date, issuer, rarity, ownership history or price. Those fields should only appear when a verified inventory record supports them.

Provenance architecture

History should be structured, not buried.

The production system should model provenance as a timeline of claims, documents, owners, dates, confidence and supporting evidence.

Stage 01

Source record received

Owner or seller materials enter the registry as evidence, not automatically as verified fact.

Stage 02

Evidence reviewed

Documents, photographs, inscriptions and measurements are compared for consistency.

Stage 03

Public provenance state

Only supportable claims move to the client-facing object page. Unresolved claims remain labelled or internal.

Evidence gallery

The object page should behave like a dossier, not a product tile.
