# Image sources used in working build

This working build deliberately mixes ZA Collectibles project imagery with high-resolution reference photography so that the brand does not visually collapse into a portfolio of only one source set. ZA Collectibles imagery is concentrated in the Packaging & Presentation and selected-work sections.

External reference imagery is loaded from Wikimedia Commons using Special:Redirect URLs. The selected external images are public domain or CC0 where possible.
